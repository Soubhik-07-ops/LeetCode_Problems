## Source Code

```
class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        n = len(nums)
        k = (n + 1) // 2                # number of even positions
        # Sort by absolute value descending
        nums.sort(key=lambda x: -abs(x))
        pos = sum(x * x for x in nums[:k])
        neg = sum(x * x for x in nums[k:])
        return pos - neg
```

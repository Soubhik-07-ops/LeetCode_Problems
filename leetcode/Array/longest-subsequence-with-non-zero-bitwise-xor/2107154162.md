# Longest Subsequence With Non-Zero Bitwise XOR

## Source Code

```
class Solution:
    def longestSubsequence(self, nums: List[int]) -> int:
        n = len(nums)
        total = 0
        for x in nums:
            total ^= x
        
        if total != 0:
            return n
        
        # total == 0: check if any non-zero element exists
        for x in nums:
            if x != 0:
                return n - 1
        
        return 0  # all zeros
```
